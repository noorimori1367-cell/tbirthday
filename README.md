# یادآور تولد

اپ اندرویدی فارسی برای ثبت تاریخ تولد با تقویم شمسی و فرستادن یادآوری یک روز پیش از تولد.

## دریافت APK بدون Android Studio

هر بار که کد تغییر کند، گیت‌هاب به‌طور خودکار نسخهٔ قابل نصب برنامه را می‌سازد:

1. در مخزن، وارد بخش **Actions** شوید.
2. آخرین اجرای «ساخت APK اندروید» را باز کنید.
3. در پایین صفحه، از قسمت **Artifacts**، فایل **YadAvar-debug-APK** را دانلود کنید.
4. فایل ZIP را باز کنید و `app-debug.apk` را به گوشی منتقل و نصب کنید.

هنگام اولین اجرا، اجازهٔ ارسال اعلان را تأیید کنید. تاریخ‌ها به‌شکل شمسی ذخیره می‌شوند و برنامه روزی یک‌بار نزدیک ساعت ۹ صبح، تولد فردا را یادآوری می‌کند.

# یادآور تولد

اپ اندرویدی فارسی برای ثبت تاریخ تولد با تقویم شمسی و فرستادن یادآوری یک روز پیش از تولد.

## اجرا

1. پوشهٔ `birthday-reminder` را در Android Studio باز کنید.
2. اجازهٔ اعلان‌ها را هنگام اجرای نخست تأیید کنید.
3. روی گوشی، تولدها را ثبت کنید؛ بررسی یادآوری‌ها روزی یک‌بار نزدیک ساعت ۹ صبح انجام می‌شود.

تاریخ‌ها به‌صورت شمسی ذخیره می‌شوند و تبدیل تقویم داخل برنامه انجام می‌شود؛ بنابراین برنامه برای این بخش به اینترنت نیاز ندارد.
